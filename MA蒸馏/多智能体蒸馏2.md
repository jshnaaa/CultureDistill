# 多智能体蒸馏2

**多智能体蒸馏**：将多个 LLM 智能体在协作辩论中产生的推理能力压缩到单个小模型，减少推理时间和部署成本，同时保持准确性和鲁棒性。 

**依据蒸馏信号的性质，可归纳为三种技术路线**： 

- **轨迹蒸馏**：用完整推理轨迹训练学生模型，复现推理过程。 

- **奖励蒸馏**：用步骤级奖励或偏好对训练，传授纠错能力。 

- **免训练蒸馏**：直接复用教师生成的可执行工具模块，无需训练即可迁移能力。 

> **核心区别**：轨迹蒸馏传“推理路径”，奖励蒸馏传“推理评判”，免训练蒸馏传“推理工具”。

# 一、轨迹蒸馏

轨迹蒸馏以**多智能体辩论产生的完整推理轨迹**为核心监督信号，训练学生模型内化多智能体的推理过程。与仅蒸馏最终答案的方式不同，**轨迹蒸馏保留了智能体间的动态依赖关系**，使学生模型不仅学会“答什么”，更学会“怎么推”。

## 1\.1 SMAGDi: Socratic Multi Agent Interaction Graph Distillation for Efficient High\-Accuracy Reasoning

- **标题**：SMAGDi: Socratic Multi Agent Interaction Graph Distillation for Efficient High Accuracy Reasoning

- **链接**：[https://arxiv\.org/abs/2511\.05528](https://arxiv.org/abs/2511.05528)

- **发表信息**：NeurIPS 2025

- **作者团队**：Aayush Aluru、Myra Malik、Samarth Patankar（共一）、Spencer Kim、Kevin Zhu、Sean O'Brien、Vasu Sharma；来自 Algoverse AI Research

- **研究动机**

    - 多智能体系统通过多智能体协作辩论获得比单模型更高的推理准确率，但其反复多轮辩论带来巨大计算开销，难以在常规环境中部署，缺乏可独立推理的统一模型。

    - 此前的 **MAGDi** 用有向图表示多智能体推理轨迹并蒸馏到小模型，但存在明显短板：**未能充分捕捉辩论的深度与协作推理模式**，本质上仍是单一架构的输出复现，无法刻画智能体之间“你来我往”的反复论证动态。

    - 核心研究问题是：**如何通过苏格拉底式思维链（Socratic CoT）从多智能体系统蒸馏出一个学生模型，在大幅降低计算成本的同时保持甚至超越其推理能力？**

- **核心贡献**

    - 本文提出 **SMAGDi**（Socratic Multi-Agent Interaction Graph Distillation），核心创新有三点：

        1. 将 **苏格拉底式思维链（SCoT）蒸馏与多智能体交互图表示相结合**，用**分解器（decomposer）+ 求解器（solver）的双模块架构**替代 MAGDi 的单一架构，更好地复现 MAS 的分步推理与协作动态；

        2. 设计**五人格智能体辩论 + 动态权重优化机制**：五个具有不同领域人格（律师、科学家、数学家、伦理学家、历史学家）的智能体进行角色对齐的辩论，并按训练表现动态分配影响权重；

        3. 设计**四项协同损失的复合训练目标**（语言建模 + 图节点分类 + 对比推理 + 嵌入对齐），在 StrategyQA 和 MMLU 上**将 40B 多智能体系统压缩为 6B 学生模型，保留其 88% 的准确率**，全面超越 MAGDi、标准 KD 和微调基线。

- **研究方法**

    - **什么是苏格拉底式思维链**：SCoT（Socratic Chain-of-Thought）是一种知识蒸馏范式，核心思想是**用两个协作的学生模型模拟苏格拉底式追问**。一个"分解器（decomposer）"负责将复杂问题拆解为若干子问题——就像苏格拉底通过层层追问引导学生思考，另一个"求解器（solver）"逐一回答子问题并整合为最终答案。与单一模型直接生成答案不同，SCoT 让学生模型通过"提问 → 回答 → 再提问"的递归过程实现多跳推理。但原始 SCoT 只用单一教师的逻辑，无法获得多视角辩论的深度。

    - **SMAGDi 的核心创新在于：把 SCoT 的分解-求解范式与多智能体交互图蒸馏相结合**——先用多智能体辩论产生高质量推理轨迹与交互图结构，再通过 SCoT 双架构让小模型内化这种多跳推理能力。

    - **第一步：多智能体辩论与交互图构建**

        - **五人格智能体辩论**：给定问题 $P_i$，五个共享 Llama 3.1-8B-Instruct 的智能体（律师、科学家、数学家、伦理学家、历史学家）以**角色对齐 prompting** 分别从各自专业视角分析同一问题。

        - **动态权重优化**：辩论开始前，先根据每个智能体在训练样本上的准确率计算权重 $w_i = \max(\varepsilon, \text{accuracy}_i)$ 并归一化（最小影响 $\varepsilon = 0.1$），使表现好的智能体在最终输出中拥有更高影响力。

        - **分层辩论与温度缩放**：辩论采用分层共识算法并在后续轮次动态升温（每轮 + 0.1）；首轮各智能体回答并给出分析，后续轮次参考其他智能体（高权重者影响更大）精炼回答，直至达成共识或完成三轮后进行加权投票。

        - **交互图构建**：将整个辩论过程编码为一张**有向图**——每个节点代表某个智能体在某一轮的推理状态（附带正确/错误标签），边分为两类：**连续性边**（同一智能体相邻回合之间，表示推理的延续）和**影响边**（跨智能体之间，带权重反映一个智能体对另一个的可信度影响）。节点特征通过句向量模型编码语义信息，同时加入位置编码保留图的拓扑结构。最终由图卷积网络（GCN）处理该图，将结构化的辩论动态转化为可用于蒸馏的监督信号。 

    - 【插图】原论文 **Figure 1**（Page 3）：SMAGDi 整体训练流水线——五人格智能体辩论 → 交互图构建 → 分解器/求解器蒸馏的端到端流程图。 
    - 【插图】原论文 **Figure 2**（Page 4）：NetworkX 有向图可视化示例，展示加权影响边与节点正确性标注。

    - **第二步：分解器-求解器双架构（SCoT 蒸馏）**

        - 这一步正是**苏格拉底式思维链的具体落地**。学生模型由**分解器（decomposer）和求解器（solver）**两个 Llama 3.2-3B 模型组成，两者协作模拟苏格拉底式追问过程：分解器接收原始问题 $P_i$，生成一系列引导性子问题（"要回答 X，我们需要先知道什么？"）；求解器逐一回答这些子问题，并将中间结果串联为最终答案。这种"提问-回答"的递归循环使得学生模型无需复杂 prompt 就能完成多跳推理。训练时，分解器和求解器分别在多智能体辩论产生的正确推理链上学习——分解器学习如何把辩论中涉及的多个论证角度拆解为子问题，求解器学习如何基于这些子问题给出准确回答。推理时两者递归配合，实现零样本多跳推理。

    - **第三步：四项协同损失的复合训练目标**

        - 图结构与四类样本（正确推理链、错误推理链、分解器子问题、求解器回答）一并传给学生模型，四项损失联合优化：

            - **语言建模损失**（$\mathcal{L}_{\text{LM}}$，α 加权）：标准自回归交叉熵，保证分解器和求解器输出的流畅性；

            - **节点分类损失**（$\mathcal{L}_{\text{node}}$，β 加权）：GCN 对节点（中间推理步骤）做二值交叉熵分类，监督推理步骤的结构正确性；

            - **对比推理损失**（$\mathcal{L}_{\text{contrast}}$，γ 加权）：基于 margin 的排序损失 $\frac{1}{N}\sum \max(0, 1 - s_i^+ + s_i^-)$，使正确推理链得分高于错误推理链至少 1；

            - **对齐损失**（$\mathcal{L}_{\text{align}}$，δ 加权）：分解器与求解器隐状态之间的 MSE，保证两个模块的内部表示语义一致。

        - 总损失 $\mathcal{L}_{\text{total}} = \alpha \mathcal{L}_{\text{LM}} + \beta \mathcal{L}_{\text{node}} + \gamma \mathcal{L}_{\text{contrast}} + \delta \mathcal{L}_{\text{align}}$，实验中权重取 1\.0/1\.0/0\.1/0\.5。前三项继承自 MAGDi，对齐损失为本文新增。

- **实验设计与结果**

    - **评估概述**：在 **StrategyQA**（分析性推理）和 **MMLU**（通用知识）两个基准上评估。MAS 智能体为 Llama 3\.1\-8B\-Instruct，学生分解器/求解器均为 Llama 3\.2\-3B（另用 Llama 3\.2\-1B 做规模消融）。基线为 MAGDi、标准知识蒸馏（SKD）、LoRA 微调基线（F\-Baseline），均以精确匹配准确率、零样本推理评估，学习率 5e\-5。

    - **MAS vs\. SAS**：多智能体系统显著优于单智能体系统，StrategyQA \+6\.3%、MMLU \+7%（84\.2% vs\. 77\.9%；76\.4% vs\. 69\.4%），验证了蒸馏源的有效性。

    - **主要蒸馏结果（Table 2）**：**3B SMAGDi 在 StrategyQA 上达 74\.6%、MMLU 上达 66\.1%**，全面超越 3B MAGDi（68\.3%/64\.0%，分别 \+7\.3%/\+2\.1%）、标准 KD（62\.7%/63\.0%，\+12\.9%/\+3\.1%）和微调基线（67\.9%/62\.4%，\+6\.7%/\+3\.7%）。**SMAGDi 将 40B 多智能体系统压缩为 6B 分解器\-求解器单元（参数减少约 7 倍），同时保留 MAS 88% 的准确率**。 
  
    - 【插图】原论文 **Table 2**（Page 8）：各蒸馏策略性能对比表（SMAGDi / MAGDi / SKD / F-Baseline 在 StrategyQA 和 MMLU 上的准确率）。

    - **规模扩展性**：1B SMAGDi（62\.4%/52\.2%）相比 1B 微调基线（59\.4%/49\.0%）分别提升 \+3\.0%/\+3\.2%，证明该流程在低算力环境下同样有效。


## 1\.2 KG\-MASD: Knowledge Graph\-Guided Multi\-Agent Distillation for Reliable Industrial Question Answering

- **标题**：Knowledge Graph\-Guided Multi\-Agent Distillation for Reliable Industrial Question Answering with Datasets

- **链接**：[https://arxiv\.org/abs/2510\.06240](https://arxiv.org/abs/2510.06240)

- **发表信息**：arXiv 2025

- **作者团队**：Jiqun Pan、Zhenke Duan、Jiani Tu、Anzhi Cheng、Yanqing Wang（通讯）；来自中南财经政法大学，Zhenke Duan 兼属杭州灵幕创想科技

- **研究动机**

    - 工业问答系统对安全性和输出可靠性要求极高——在设备故障诊断、化工安全等高风险场景中，模型的细微错误或“幻觉”可能导致严重后果。直接部署大模型面临**核心矛盾**：一方面大模型难以在资源受限的边缘设备上高效部署；另一方面其推理过程缺乏验证机制，无法满足工业级可信度要求。

    - 现有方法各有局限：**传统单教师蒸馏**难以忠实迁移知识密集领域的复杂推理模式，导致学生模型“知其然不知其所以然”；**多智能体系统**虽能提升推理深度，但智能体间不受约束的迭代可能导致**推理循环失控**，决策过程是“黑箱”，缺乏可验证的外部锚点。

    - 作者据此提出：**将知识图谱作为可验证的结构化先验引入多智能体蒸馏，把蒸馏过程重新定义为知识引导的协作决策过程，并形式化为马尔可夫决策过程（MDP）**，使先验质量直接决定学生模型学习的收敛性。

- **核心贡献**

    - 本文提出 **KG\-MASD**（Knowledge Graph\-guided Multi\-Agent System Distillation），核心贡献有三点：

        1. 提出将**结构化知识图谱先验显式融入多智能体蒸馏**的框架，通过 **KG 引导的 MDP 模型**约束多智能体推理路径并提供验证依据，同时提升推理能力与输出可靠性；

        2. 构建了**首个带垂直领域标注的工业 QA 数据集和大规模工业知识图谱**，为面向可信度的蒸馏研究提供评测基准；

        3. 给出**理论分析**（基于 Blackwell 占优证明 KG 先验可提升蒸馏效率），并通过大量实验验证 KG\-MASD 显著增强可靠性、缓解幻觉，**相比各类单教师与多智能体基线准确率提升 2\.4–20\.1%**。

- **研究方法**

    - **整体思路**：KG-MASD 把蒸馏分为三个阶段——先构建可验证的知识图谱作为推理锚点，再通过多智能体协作在知识图谱引导下生成高质量推理轨迹，最后将这些轨迹蒸馏进小模型。核心理念是：**用结构化的外部知识（知识图谱）约束多智能体推理路径，使其既准确又可验证，从而为蒸馏提供比"自由辩论"更可靠的监督信号**。

    - **第一步：构建全局知识图谱**

        - 从原始工业文本中自动抽取实体和关系，构建全局知识图谱 $G_g = \{(H, R, T)\}$（头实体、关系、尾实体三元组的集合）。这张图谱相当于一个**可查询的外部事实库**，后续多智能体在推理时必须锚定在图谱中已有的实体和关系上，而不能随意"编造"知识。

    - **第二步：五智能体协作生成知识引导的推理轨迹**

        - 给定用户查询，**五个智能体分工协作**：KG Master 将查询分解为子任务并在全局图谱中定位相关关系；Entity Extractor 和 Relation Extractor 分别从文本中抽取候选实体和关系；KR Distiller 将候选聚合为局部知识三元组；**Verifier 对生成的三元组做正确性校验**——不通过的退回给前面的智能体重新精炼。

        - 这种"生成-校验-精炼"的循环保证了最终产出的三元组**经过外部知识图谱验证**，而非仅靠语言模型的自信度。相比不受约束的多智能体辩论，KG 引导下的推理路径更可控、更少幻觉。 
      
    - 【插图】原论文 **Figure 4**（Page 13）：KG-MASD 整体框架图——五智能体协作提取知识图谱、MDP 引导蒸馏的端到端流程。

    - **第三步：MDP 建模与理论保证**

        - 作者将上述过程形式化为**马尔可夫决策过程（MDP）**：**状态**编码当前查询、检索到的上下文与已积累的三元组集合；**动作**是智能体推断或验证新三元组；**奖励**是基于当前知识状态产生正确答案的对数似然。每一步迭代都向状态中注入更多经验证的三元组，逐步丰富语义锚定。

        - 为衡量知识图谱先验的质量，定义**先验质量指数** $\gamma \in [0,1]$（已积累三元组对正确答案的归一化条件互信息）：$\gamma$ 越高，说明当前知识状态对预测正确答案的帮助越大。

        - 论文借助 **Blackwell 占优（Blackwell dominance）**理论给出关键保证。Blackwell 占优是统计决策论中的经典概念，直观含义是：**如果观察 A 能被"加噪"退化为观察 B，那么 A 一定比 B 更有信息量——在任何决策问题中，用 A 做决策都不会比用 B 差**。论文证明：当 $\gamma$ 更高时（即积累了更多高质量三元组），所对应的知识状态 Blackwell 占优 $\gamma$ 更低时的状态，因此**一步奖励单调不减**。这意味着：**知识图谱先验质量越高，蒸馏效果保证越好**——这不是经验观察，而是理论上的单调性保证。 
    
    - 【插图】原论文 **Figure 5**（Page 19）：智能体轨迹随迭代收敛的可视化——随时间推进各智能体推理路径趋于一致。

    - **第四步：蒸馏进小模型**

        - Verifier 校验通过的局部三元组被整合为小规模局部知识图谱，并据此构造**显式锚定在已验证三元组上的指令微调数据集**（即每条训练样本都附带经验证的知识依据）。最终用参数高效微调（LoRA）将教师多智能体系统的推理能力蒸馏进小型学生模型。由于训练数据本身经过知识图谱验证，学生模型不仅学到"怎么答"，还学到"依据什么答"，从而提升输出的可靠性与可解释性。

- **实验设计与结果**

    - **评估概述**：在作者自建的工业 QA 数据集（涵盖交通、健康、环境、设备、生产、电力、防灾、通用八大主题）上评估。**MAS 骨干为 DeepSeek\-V2**，学生模型为 **Qwen2\-7B 和 Llama3\.1\-8B**。LoRA 超参：rank 16、alpha 64、学习率 2e\-5、batch size 64、5 个 epoch，在两张 NVIDIA 3090 上训练。评测指标为 BLEU\-4、ROUGE\-1/2/L，并辅以人工评估和 LLM\-as\-a\-Judge。基线分两类：MAS 辅助蒸馏（MAD、Self\-Reflect、MAPS、Self\-Consistency）和单 LLM 蒸馏（Vanilla 微调、Step\-by\-Step 蒸馏、In\-Context Learning、零样本）。

    - **MAS 辅助蒸馏对比（Table 3）**：KG\-MASD 在所有指标上一致领先。Llama3\.1\-8B 上 BLEU\-4/ROUGE\-1/2/L 达 66\.812/65\.539/51\.573/49\.524（相比次优基线 BLEU\-4 \+3\.05）；Qwen2\-7B 上达 68\.148/66\.855/52\.605/50\.474，均显著高于 MAD、MAPS、Self\-Consistency。
  
    - 【插图】原论文 **Table 3**（Page 25）：不同蒸馏方法与模型在工业 QA 数据集上的 BLEU-4/ROUGE-1/2/L 对比表。

    - **单 LLM 蒸馏对比（Table 3）**：相比 Vanilla 微调等单教师基线，KG\-MASD 在四项指标上提升达 **\+10\.48 ～ \+12\.28**，验证了 KG 引导先验对可靠推理迁移的关键作用。综合所有对比，KG\-MASD **相比各类基线准确率提升 2\.4–20\.1%**，并显著缓解幻觉、增强工业场景可信度。


## 1\.3 小结

**优点**

- **复现协作推理结构**：通过蒸馏多智能体交互图或苏格拉底式分步轨迹，学生模型学到的是“如何分解问题、如何相互论证”，而不仅是最终答案，在多步推理任务上更稳健。

- **可引入结构化先验增强可信度**：KG\-MASD 用知识图谱作为可验证锚点约束推理路径，显著缓解幻觉，并通过 Blackwell 占优给出先验质量越高、蒸馏效果越好的理论保证，适合工业级高可靠场景。

**缺点**

- **工程成本高**：生成交互图需多智能体多轮运行，序列长、显存压力大；图结构蒸馏还需额外的图编码器（GCN），工程适配复杂，黑盒模型难直接套用。

- **依赖蒸馏源与先验质量**：学生上限受教师多智能体系统能力约束，知识图谱构建（GraphRAG、实体/关系抽取）若出错或覆盖不足，会直接拉低蒸馏效果。

# 二、奖励蒸馏

奖励蒸馏不直接复制完整推理轨迹，而是把多智能体辩论中蕴含的**评判信号（奖励、偏好或更优的概率分布）**作为监督，通过强化学习或 on\-policy 蒸馏让学生模型在自己生成的轨迹上"被纠错"，从而内化辩论的择优与纠错能力。

## 2\.1 Latent Agents: A Post\-Training Procedure for Internalized Multi\-Agent Debate

- **标题**：Latent Agents: A Post\-Training Procedure for Internalized Multi\-Agent Debate

- **链接**：[https://arxiv\.org/abs/2604\.24881](https://arxiv.org/abs/2604.24881)

- **发表信息**：arXiv 2026

- **作者团队**：John Seon Keun Yi、Aaron Mueller、Dokyun Lee；来自波士顿大学

- **研究动机**

    - 多智能体辩论能显著提升 LLM 推理质量，但需要**多个智能体实例多轮交互**，token 开销和延迟极高，难以实际部署。

    - 一个自然的问题是：**能否把"多个智能体辩论"这一外部过程内化进单个模型，让它在一次前向生成中自己完成多视角辩论与自我纠错？**——即把"显式多智能体"转化为模型内部的"潜在智能体（latent agents）"。

    - 此外，作者希望该方法不仅高效，还能**让内部智能体可被解释和操控**：通过激活空间干预定位并调控这些潜在智能体，甚至抑制恶意人格。

- **核心贡献**

    - 提出 **IMAD**（Internalized Multi\-Agent Debate）后训练流程，核心贡献有三点：

        1. 设计 **两阶段训练（SFT \+ 强化学习）\+ 动态奖励调度**：先用辩论轨迹做监督微调，再用 GRPO 强化学习，并通过**衰减的格式奖励 \+ 长度退火/裁剪**逐步引导模型从"模仿辩论格式"过渡到"高效内化辩论"；

        2. **大幅压缩推理成本**：内化后的单模型仅用原始辩论 **6\.3–21\.1% 的 token**（约 5–16 倍效率提升，最多减少 93% token），即可达到甚至超过显式多智能体辩论的准确率；

        3. 提出 **智能体子空间引导（agent subspace steering）**：用 CAA / 均值差方向在激活空间定位"潜在智能体"，可控制其影响、提升表现（AUC 平均 \+15\.41%），并能**抑制恶意人格特质**（如 evil、hallucination）。

> 【插图】**Figure 1**（Page 3）：IMAD 流水线概览——辩论数据收集 → SFT 阶段 → GRPO 强化学习 → 内化后的单模型输出。

- **研究方法**

    - **第一步：构造辩论轨迹并 SFT**

        - 用 GPT\-3\.5\-turbo 作教师，配置 **n=3 个智能体、m=2 轮辩论**在算术任务上生成 944 条辩论轨迹，将多智能体交互整理为单序列。

        - 用这些轨迹对基座模型（LLaMA\-3\.1\-8B / Qwen2\.5\-7B / Mistral\-Nemo\-12B）做 **监督微调**，让模型学会在单序列内复现"提出—质疑—修正"的辩论结构。

    - **第二步：GRPO 强化学习 \+ 动态奖励调度**

        - 在 SFT 基础上做 **GRPO 强化学习**，奖励由答案正确性主导，并叠加两类动态调度：

            - **衰减格式奖励**：辩论结构奖励从 1\.0 逐步衰减到 0\.05，初期鼓励模型保留辩论格式，后期解除约束让模型自由压缩；

            - **长度退火与裁剪**：目标长度从 2000 token 退火到 500 token，促使模型在保持准确率的同时大幅缩短输出，实现"高效内化"。 
          
      - 【插图】原论文 **Table 1**（Page 5）：IMAD 主要结果——各模型在 GSM8K / MMLU-Pro / BBH 上的准确率及 token 消耗对比（IMAD vs Debate vs SFT vs Base）。

    - **第三步：智能体子空间引导与可解释性**

        - 用对比激活添加（CAA）/ 均值差（difference\-in\-means）从激活中提取"潜在智能体"对应的方向向量，在推理时**沿该子空间加/减干预**：

            - 正向引导可增强特定智能体影响，提升下游表现；

            - 负向引导可**抑制恶意人格**（如刻意作恶 evil、制造幻觉 hallucination），增强安全性与可控性。

- **实验设计与结果**

    - **评估概述**：基座模型 LLaMA\-3\.1\-8B、Qwen2\.5\-7B、Mistral\-Nemo\-12B；在 **GSM8K、MMLU\-Pro、BBH** 三个基准上各取 1000 样本、跑 3 次取均值。对比对象包括基座、单纯 SFT、显式多智能体辩论（Debate）等。

    - **主要结果（Table 1）**：IMAD 在三个基准上一致优于基线，例如 LLaMA 版 IMAD 在 GSM8K 85\.20、MMLU\-Pro 62\.00、BBH 58\.53，达到或超过显式辩论的水平，**而仅消耗显式辩论 6\.3–21\.1% 的 token**（5–16 倍效率提升，最多减少约 93% token）。

    - **可解释性与安全性**：智能体子空间引导使 AUC 平均提升 \+15\.41%（最高单项 \+12\.7%）；负向引导能有效抑制 evil、hallucination 等恶意特质，验证了"潜在智能体"既可被读取又可被操控。

> 【插图】原论文 **Figure 3**（Page 8）：恶意特质抑制实验——evil / hallucination steering 前后的 trait score 与 GSM8K 准确率对比。


## 2\.2 MAD\-OPD: Breaking the Ceiling in On\-Policy Distillation via Multi\-Agent Debate

- **标题**：Breaking the Ceiling in On\-Policy Distillation via Multi\-Agent Debate

- **链接**：[https://arxiv\.org/abs/2605\.01347](https://arxiv.org/abs/2605.01347)

- **发表信息**：arXiv 2026

- **作者团队**：Jianze Wang（华中科技大学，阿里巴巴实习）等，Yong Xie、Qianglong Chen（通讯）

- **研究动机**

    - **On\-Policy 蒸馏（OPD）**让学生在自己生成的轨迹上向单一教师对齐分布，是当前高效蒸馏的主流，但其性能存在天花板：**单一教师的能力上限直接决定了学生的上限**，且单教师在不同任务类型上的监督质量参差不齐。

    - 直接堆叠多个教师（如简单平均其分布）又会因教师之间分歧/冲突而引入噪声，反而损害效果。

    - 核心问题是：**如何让多个教师在 on\-policy 蒸馏中协同提供监督，既突破单教师上限，又避免教师冲突带来的噪声？**

- **核心贡献**

    - 提出 **MAD\-OPD**（Multi\-Agent Debate On\-Policy Distillation），核心贡献有三点：

        1. **首次将多智能体辩论引入 on\-policy 蒸馏**，把多个教师组织成辩论者，对学生的 on\-policy 轨迹给出协同监督，突破单教师天花板；

        2. 提出 **任务自适应散度 \+ 基于置信度的动态教师加权**：对智能体类任务用 JSD、对代码类任务用反向 KL，并按各教师置信度动态分配权重，缓解教师冲突；

        3. 在 6 组教师\-学生配置、多个权威基准上**全部排名第一**，相比单教师 OPD，agentic 任务平均 \+2\.4%、code 任务平均 \+3\.7%。

- **研究方法**

    - **核心思路**：标准 On\-Policy 蒸馏（OPD）让学生在自己采样的轨迹上向**单一教师**的分布对齐。MAD\-OPD 的核心改造是：把"单一教师直接打分"替换为"**多教师先辩论达成共识，再对学生轨迹进行 token 级监督**"，通过辩论产生的 privileged information 建立比单教师更强、更可靠的监督信号。

    - **第一步：多智能体辩论生成 Privileged Information**

        - 给定 $K$ 个教师 $\{T_1, \ldots, T_K\}$ 和当前状态 $s_m$（单轮任务为 prompt，多步 agentic 任务为历史上下文），教师之间进行 $R$ 轮辩论：

            - **第 1 轮**：每个教师独立生成各自的回答 $h_r^k$，不看其他教师输出，以此产生**多样性的初始观点**；

            - **第 2\~R 轮**：每个教师在看到所有其他教师此前所有轮次的回答后，修正自己的回答——通过这种迭代交换，教师之间**互相挑战和纠错**，让单个教师可能犯的错误在辩论中暴露并被修正。

        - 最终得到完整辩论记录 $H_m^R = \{h_r^k\}_{k,r}$，作为**仅对教师可见的 privileged context**：教师在后续评分时能看到辩论过程，而学生看不到。这构建了教师与学生之间的**信息不对称（privileged p–q gap）**，使教师的监督信号比"不辩论直接打分"更准确、更有深度。

        - 【插图】原论文 **Figure 2**（Page 6）：MAD-OPD Pipeline 全流程图——学生 on-policy 采样 → 多教师辩论 → force-decode → 任务自适应散度计算。

    - **第二步：基于置信度的动态教师加权**

        - 辩论结束后，每个教师 $T_k$ 基于完整辩论历史 $H_m^R$ 给出一个**自报告置信度** $c_k \in [0, 100]$，反映其经过辩论修正后对当前问题的确信程度。

        - 通过 softmax 归一化得到教师权重 $w_k = \frac{\exp(c_k / 100 \cdot \tau)}{\sum_j \exp(c_j / 100 \cdot \tau)}$：**辩论中立场被强化的教师权重更高，立场被削弱的教师权重更低**。这不是简单的均匀平均，而是让"辩论后更有把握"的教师主导监督，从根源上缓解多教师冲突。

    - **第三步：任务自适应散度选择**

        - 不同任务类型的最优蒸馏散度不同，论文给出理论证明并据此设计自适应选择规则：

            - **多步智能体任务（agentic）→ JSD**：agentic 任务涉及多步工具调用，错误会级联传播。JSD 的关键优势是**梯度有界**（$\|\nabla_z \text{JSD}\|_\infty \le 2$，无论教师\-学生分布差距多大），保证长轨迹训练的梯度稳定性。而反向 KL 在教师给出低概率的 token 上梯度会爆炸，不适合 agentic 场景。

            - **代码生成任务（code）→ 反向 KL**：代码存在多种正确实现（不同算法、命名、结构），教师分布是多峰的。反向 KL 的**模式集中（mode\-seeking）**特性使学生集中在最主要的一条实现路径上，避免"拼接"不兼容的代码片段。而 JSD 和正向 KL 都会保留次要模式，导致生成不连贯的混合代码。

    - **第四步：Token 级蒸馏损失**

        - **Force\-decode 阶段**：让学生在自身 on\-policy 采样的输出 $\hat{y}$ 上做 force\-decode 得到学生分布 $p_S(\cdot \mid s_m, \hat{y}_{<t})$；每个教师在相同 token 上 force\-decode，但额外拼接辩论记录作为上下文，得到教师分布 $p_{T_k}(\cdot \mid s_m, H_m^R, \hat{y}_{<t})$。

        - **加权聚合**：MAD\-OPD 的最终损失为各教师散度的置信度加权和：

            $$\mathcal{L}_{\text{MAD-OPD}}(\theta) = \frac{1}{|\hat{y}|} \sum_{t=1}^{|\hat{y}|} \sum_{k=1}^{K} w_k \cdot D\big(p_{T_k}(\cdot \mid s_m, H_m^R, \hat{y}_{<t}) \| p_S(\cdot \mid s_m, \hat{y}_{<t})\big)$$

            其中 $D$ 按任务类型选择（agentic 用 JSD，code 用反向 KL）。梯度只更新学生 $\pi_\theta$，教师参数冻结。

    - **第五步：OPAD——面向多步 Agentic 任务的外循环**

        - 对于多步智能体任务，不能一次生成全部轨迹再算损失，因为**每步动作会改变环境状态**。OPAD（On\-Policy Agentic Distillation）设计了"动作\-环境\-观察"的循环：学生每走一步 $a_m$，环境返回观察 $o_m$，然后教师在这一步上辩论并给出监督信号，轨迹总损失为各步损失之和。这保证了监督信号始终**基于学生实际产生的轨迹状态**，而非假设的理想状态。

- **实验设计与结果**

    - **评估概述**：模型基于 **Qwen3 / Qwen3\.5** 系列，共 **6 组教师\-学生配置**（学生 1\.7B–14B，教师 8B–32B）。训练数据为 **ToolACE（约 16K agentic 样本）\+ OpenThoughts3（30K code 样本）**。评测基准：agentic 用 **BFCL\-v4、τ²\-Bench、VitaBench**；code 用 **LiveCodeBench\-v6、MBPP+**。基线包括 Base、单教师 OPD、多教师 OPD（MT\-OPD）、多教师序列 KD（MT\-SeqKD）。

    - **主要结果（Table 1）**：MAD\-OPD 在全部 6 组配置上均排名第一。以 **14B\+8B→4B** 配置为例，平均分 **34\.66**，显著高于单教师 OPD 的 31\.72；综合来看相比单教师 OPD，**agentic 任务平均 \+2\.4%、code 任务平均 \+3\.7%**，验证了多智能体辩论协同监督对突破单教师蒸馏天花板的有效性。

> 【插图】原论文 **Table 1**（Page 8）：6 组教师-学生配置主结果表——各方法在 BFCL-v4 / τ²-Bench / VitaBench / LiveCodeBench-v6 / MBPP+ 上的得分。

## 2\.3 小结

**优点**

- **内化辩论、纠错而非仅答案**：奖励/评判信号让学生学到“如何择优、如何修正错误推理”——IMAD 把多智能体辩论压进单模型，MAD\-OPD 用辩论分布在学生自身轨迹上纠偏，多步推理更稳。

- **突破单教师天花板**：MAD\-OPD 通过多教师辩论 \+ 任务自适应散度 \+ 置信度动态加权，既汇聚多教师知识又抑制冲突噪声，全部配置排名第一；IMAD 的子空间引导还能定位并抑制恶意人格，提升可控性与安全性。

**缺点**

- **教师/奖励信号成本高**：构建步骤级奖励、偏好对或多教师辩论分布需要多模型多轮参与，数据生成的时间与 API 调用成本较大。

- **存在噪声风险**：教师出错、反馈不一致或多教师分歧都会引入奖励噪声，散度选择与加权策略若不当可能使训练偏离正确方向。

- **对学生与超参敏感**：基础推理能力不足的小模型难以吸收复杂纠错信号；GRPO 的长度退火、格式奖励衰减及辩论轮数/教师数等超参需要细致调优才能稳定收益。
